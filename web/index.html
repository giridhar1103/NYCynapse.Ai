How it answers

One question. The right source, cheapest first.

Most questions about the city are already sitting in the city's own records. The guide asks those first, through governed metrics that always add up the same way. When you ask about right now, it reads live city feeds. Only when neither has it does it search the web, and it says so.

Underneath

A lakehouse of New York, refreshed around the clock.

City sources land in a DuckLake lakehouse: Parquet files with a Postgres catalog, no raw copies kept. dbt builds clean gold tables, a semantic layer defines every metric and join once, and the guide reads only through that layer.

IngestBatch loaders on schedules, live pollers every minute for subway and Citi Bike. Failed batches are kept and replayed.
StoreDuckLake: Parquet plus a Postgres catalog with snapshots, so any answer can be rerun against the data it saw.
Modeldbt gold facts and dimensions, tested daily, with a freshness table the guide checks before it answers.
Govern39 metrics, 46 declared joins, place names and domain rules. The model fills in a plan; code writes the SQL.

Open by design

Every tool is an MCP server.

The guide is an MCP host: it reaches the lake, the live city feeds and the web through Model Context Protocol servers. The same servers work in Claude Desktop or any MCP client, so you can bring New York into your own assistant.

Guardrails

Safe to open to everyone.

New York onlyOff-topic requests, lookups of private people and harmful asks are declined politely.
Web text is dataPages and search results are quoted to the model as untrusted material; instructions inside them are ignored.
Read-only everythingNo tool can write. SQL is parsed and limited to one SELECT on gold tables.
No private networkPage reads resolve and check every address and redirect; local and cloud metadata addresses are refused.
Bounded by designBot check, hourly limits, a few steps and a time limit per answer, and a daily budget for the whole site.
Private by defaultNothing anyone asks is shown to others. Conversations are kept 30 days for quality review, then deleted.

Measured, too: on 167 test questions with known answers, the full pipeline answers 74 to 76% exactly right with the best models, against 59 to 67% for the same models given the raw schema. See the evals.
