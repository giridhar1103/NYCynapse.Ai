How often it is right.

Every version is scored on a fixed set of questions with known answers, run against a frozen copy of the lake so the numbers stay comparable. A result counts as correct when its rows match the reference query, not when the SQL looks similar. Questions that should be refused, like future dates or data the city does not publish, count too.

Five builds are compared, each adding one piece. The holdout questions are kept out of the repository and were never used while building.

The builds

0Full schema

The model gets every table and column and writes SQL. The usual starting point.

1Routed

Questions go to a subject area first; only the tables that matter are shown.

2Grounded

Names, places and periods are matched to real values and exact dates before writing SQL.

3Planned

The model fills in a typed plan; SQL is compiled from fixed metric definitions and join paths.

4With examples

As 3, plus reviewed question and plan pairs found by similarity.
